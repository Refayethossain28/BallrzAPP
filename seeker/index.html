⛏ Crawl & index the web yourself

Seeker ships with the Ballrz universe pre-indexed, and it can crawl real pages into your on-device index — the crawler respects robots.txt and noindex, canonicalises URLs and strips tracking params. In the browser it can fetch this site and CORS-open pages; run the zero-dependency companion server (node seeker/server.mjs) and it can crawl any site.

⌘ Search operators, !bangs & how Seeker works
"exact phrase"words must appear consecutively
-wordexclude documents containing it
title:wordthe word must be in the title
site:host · url:pathrestrict by host / URL
!w !g !yt !gh !so !hn !maps …bangs — jump straight to that site’s search
12*(3+4)^2 · 5 km to miles · time in tokyoinstant answers, computed on-device

Under the hood: a from-scratch Porter stemmer, a positional inverted index, BM25 ranking with field weights, proximity and coverage, Damerau–Levenshtein typo forgiveness, frequency-weighted did-you-mean, best-window snippets — and live results from Wikipedia, Hacker News, Stack Overflow and Open Library, fused into one ranking by Reciprocal Rank Fusion. Every part is pure, deterministic and unit-tested (npm run test:seeker).
