Every hash this app computes is genuine Bitcoin-style proof-of-work — the same double-SHA-256 over the same 80-byte header layout. What no phone or browser can do is compete with warehouses of ASIC hardware. Apps that promise you real bitcoin from tapping a phone are either simulations or scams. Rig will never pretend: BTC mode earns practice shares, not money. To mine BTC for real you'd need ASIC hardware and a mining pool.

The difficulty above is a shipped estimate, not live data — and it goes stale in the flattering direction (real difficulty keeps rising, so the true wait is even longer). Look up today's value and set it here to keep the maths exact.
