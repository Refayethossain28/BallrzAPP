Developer tools (not browser-openable — see their READMEs)

🖍️

Highlight text and pin sticky notes on any page; annotations persist per-URL.

⚒️
Forge — CLI toolkit
Scan directories, generate HTML reports, hunt TODOs. Zero-dependency Node.
CLI
Running the suite: open any web app's index.html directly, or serve the folder (npx serve apps / python3 -m http.server) for full PWA features. Load NoteMark via chrome://extensions → Load unpacked. Run Forge with node apps/forge-cli/forge.mjs --help. The AI apps work fully offline via local engines; adding an Anthropic API key in their settings upgrades them to live Claude responses.
