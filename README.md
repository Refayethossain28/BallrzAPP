- **🧭 [Voyager — the internet browser](https://refayethossain28.github.io/BallrzAPP/voyager/)** — a real internet browser in your browser, built the honest way: the *chrome* — the part that actually is a browser — is a pure, deterministic, unit-tested engine, and the pixels come from your device's real web engine in a sandboxed frame. **Tabs** with per-tab **back/forward stacks** (branching truncates the future, exactly like the big browsers), a **smart omnibox** that classifies whatever you type — `example.com` navigates, `example com` searches, `localhost:3000`, IPs and full URLs all just work — with **frecency-ranked suggestions** drawn from your history and bookmarks as you type, a **🔒/⚠️ security chip** (https is quiet, plain http is called out), **★ bookmarks**, a **history** page with search, visit counts and per-site delete, **top sites** on the start page ranked by the classic frecency score, **🕶 private tabs** that write nothing anywhere and are dropped from the saved session *by construction*, **per-tab zoom** (25–500%), **seven search engines** — the default is **🔎 Seeker, the repo’s own search engine**, so a search in your own browser lands on your own engine (then DuckDuckGo, Google, Bing, Brave, Startpage, Ecosia), internal `voyager://` pages (start · history · bookmarks · reading · memory · reader · site · settings · about), desktop shortcuts (⌘L/⌘T/⌘W/⌘D/⌘E), and a **session that survives restarts** — tabs, stacks and scroll of where you were, restored exactly. A **⌘K command palette** jumps to any open tab, bookmark, reading item or action in one keystroke; a **📚 reading list** saves pages for later (separate from bookmarks); **🎨 themes** (dark / light / auto + five accent colours); and **🛡️ built-in ad & tracker blocking** through the proxy (on by default, a curated blocklist, Brave-style). Recognises **🧅 .onion** hidden-service addresses first-class (their own security posture) and can route them through an optional **Tor gateway**. **YouTube videos play** — paste a `youtube.com/watch`, `youtu.be` or shorts link and Voyager loads YouTube's embeddable player (works even on the static site, no server). **🛰️ Full-browser mode** for everything else: the static frame browser can't open sites that send `X-Frame-Options` (Google, YouTube's homepage, most logins) — so run the bundled companion server ([`voyager/server.mjs`](./voyager/server.mjs), zero-dependency, `npm run voyager`) and Voyager auto-switches into a real **web-proxy browser** that fetches pages server-side, strips the framing header, rewrites their links back through itself and serves them same-origin, so they load — and a **postMessage bridge** makes in-page clicks and searches drive the omnibox, history and back/forward across real sites. Deploy that server once ([`voyager/DEPLOY.md`](./voyager/DEPLOY.md)) and paste its URL into Settings, and the hosted page opens any site with no local setup (SSRF-guarded, origin-allowlisted). Honest limits stated in-app: a proxy is not a from-scratch engine (heavy apps, DRM video and logins with cookies-off may not fully work) and it sees your traffic, so you run it yourself; it's SSRF-guarded and bound to localhost. And the thing **no other browser does — 🧠 Web Memory**: because the full-browser proxy already has each page's HTML server-side, Voyager distills every page you read down to its clean article text (a from-scratch Readability-style extractor in [`voyager/proxy.js`](./voyager/proxy.js), served at `/reader`) and keeps a private, on-device, **full-text-searchable copy** of it — so months later you can find that one article by *a phrase from its body*, not just its title, and **re-read it offline** in a distraction-free **📖 Reader view** even after the live page paywalls, changes or vanishes. `voyager://memory` searches everything you've read with AND-term ranking and highlighted snippets; capture is automatic, never touches **private tabs**, and is one toggle to disable — nothing leaves the device (capped so storage can't run away). Web Memory then earns its keep three more ways: **📝 time travel** — revisit a remembered page and Voyager diffs it against the copy you actually read, raising a "changed since you read it" banner and a full edit-story view (what you read struck through, what it says now lit up), so quiet news edits, price changes and ToS tweaks stop being invisible; **⚡ TL;DR** — a from-scratch extractive summarizer (the article scored against its own word frequencies — deterministic, offline, no model) distills any Reader page to its gist in one tap; and the **🛡 tracker receipt** — the proxy counts each page's distinct tracker requests and the omnibox wears the number, with a per-site tally on `voyager://site`. Plus a **personalised start page**: a name greeting and your own **📌 pinned shortcut** tiles. **📌 Pinned tabs** ride at the front of the strip, survive the session and refuse ⌘W / ✕ until unpinned; **↔ swipe gestures** on touch screens drag you back/forward from the screen edge (a pure engine classifier decides what a drag meant, so vertical scrolling is never hijacked); and **🌐 per-site settings** (`voyager://site`) give each site its own switches — zoom that *sticks to the site* exactly like Chrome's (set it once, it re-applies every visit, 100% forgets it), and per-site opt-outs for tracker blocking and web-memory capture that override the global toggles in either direction. The whole chrome — classifier, tab lifecycle, navigation door, history ledger, frecency, suggestions, onion + proxy routing, web-memory store + full-text search, pinning, per-site overrides, swipe classification, session round-trip — is one pure clock-injected engine ([`voyager/engine.js`](./voyager/engine.js), `npm run test:voyager` — 60 tests) plus a pure, unit + integration-tested proxy ([`voyager/proxy.js`](./voyager/proxy.js), `npm run test:voyager-proxy` — 14 tests). No account, no cloud, no telemetry; fully offline shell, **installable PWA**.
- **🔎 [Seeker — the search engine](https://refayethossain28.github.io/BallrzAPP/seeker/)** — a real internet search engine built the honest way: everything that makes a search engine a *search engine* is implemented **from scratch** in one pure, deterministic, unit-tested engine ([`seeker/engine.js`](./seeker/engine.js), `npm run test:seeker` — 29 tests). The text pipeline is the real thing — case/diacritic folding, the classic **Porter stemmer** (verified against the published algorithm's vectors), a **positional inverted index** with per-field weights — and the ranking is **BM25** (the same family Lucene and Elasticsearch use) boosted by term **proximity**, **coverage** (whole-query matches beat partials) and exact-title hits. The query language is what you'd demand of a grown-up engine: `"exact phrases"`, `-exclusions`, `OR`, `title:` / `site:` / `url:` fields — plus DuckDuckGo-style **!bangs** (`!w`, `!g`, `!yt`, `!gh`, `!so`, `!maps`…) that jump you straight to the right site. It **forgives**: unknown terms fall back to banded **Damerau–Levenshtein** fuzzy matching, a frequency-weighted *did-you-mean* proposes corrections, and search-as-you-type gets prefix expansion plus suggestions. It **answers**: an on-device instant-answer box computes maths (`12*(3+4)^2` — a real recursive-descent parser, no `eval`), unit conversions (`5 km to miles`, `100 c to f`) and a world clock (`time in tokyo`) without leaving the page. And it searches the **live internet, keylessly**: Wikipedia, Hacker News, Stack Overflow and Open Library (all CORS-open APIs) are queried in parallel and **fused with your on-device index by Reciprocal Rank Fusion** into one deduped ranking with best-window highlighted snippets. Then the part no toy has: a **real crawler** — ⛏ crawl this site from the browser, or run the zero-dependency companion server ([`seeker/server.mjs`](./seeker/server.mjs), `npm run seeker`) and crawl **any site on the internet**: it identifies itself as SeekerBot, **respects robots.txt** (the Robots Exclusion Protocol parser is in the engine, longest-match-wins like Google documents) and `noindex`, canonicalises URLs (fragments and `utm_` tracking params stripped), is SSRF-guarded (hostname *and* resolved-IP), and feeds pages into your **persistent on-device index** — your index never leaves your device. Keyboard-first (`/` to focus, `j`/`k` through results), recent searches, source toggles, an *I'm Feeling Lucky* button. No account, no tracking, fully offline for everything on-device, **installable PWA**.

## Running locally

The web prototypes are zero-build single-file HTML — clone and open:

```sh
git clone https://github.com/refayethossain28/BallrzAPP.git && cd BallrzAPP
open aios/index.html                       # AIOS — the AI operating system
open voyager/index.html                    # Voyager — the internet browser
open imposter/index.html                    # pass-and-play imposter party game (3–12 players)
open ripple/index.html                     # WhatsApp-but-better private messenger
open atlas/index.html                      # Atlas — your own satnav (demo drive works offline)
open seeker/index.html                     # Seeker — the from-scratch search engine
open cusp/index.html                       # "what to do right now" — the Salience Engine
open concierge/index.html                  # ApexVIP Concierge — subscription-based
open omni/index.html                       # the do-everything super-app
open lingua/index.html                     # learn & translate any language (+ dialects)
open concepts/prototypes/flow-game/index.html
```

Live AI translations & lessons in Lingua (key stays server-side):

```sh
cd lingua
ANTHROPIC_API_KEY=sk-ant-... node server.mjs   # then open http://localhost:8788
```

Optional **Live AI categories** in Imposter (the game is fully playable without it — this only powers the “generate a pack from a theme” button; key stays server-side):

```sh
ANTHROPIC_API_KEY=sk-ant-... node imposter/server.mjs   # then open http://localhost:8790
```

Optional **Live AI** in AIOS (the OS is fully usable without it — this adds open
conversation and lets the model drive the OS; key stays server-side):

```sh
ANTHROPIC_API_KEY=sk-ant-... node aios/server.mjs   # then open http://localhost:8791
```

**Whole-internet crawling** in Seeker (the search engine works standalone — this
lets its ⛏ crawler index any site, not just same-origin/CORS-open ones; no key
needed, robots.txt respected, SSRF-guarded):

```sh
node seeker/server.mjs             # then open http://localhost:8795 (or: npm run seeker)
```

**Full-browser mode** in Voyager (the browser works standalone; this lets it open
sites that refuse to be framed, like Google — no key needed):

```sh
node voyager/server.mjs            # then open http://localhost:8790 (or: npm run voyager)
```

To make the *hosted* page open any site with no local setup, deploy that same
server once (Render / Fly / Cloud Run / a VPS) and paste its `/proxy` URL into
Voyager → Settings — see [`voyager/DEPLOY.md`](./voyager/DEPLOY.md). YouTube
*videos* already play with nothing running.

Live Claude tool-use in the concierge prototype:

```sh
cd concepts/prototypes/concierge-split
ANTHROPIC_API_KEY=sk-ant-... node server.mjs   # then open index.html, toggle "Live"
```
